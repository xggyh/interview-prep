🧠 核心心智模型 (1 sentence)

IT 不是你的敌人, 是你最稳定的盟友 — 如果你赢得他的信任. 90% IT block 不是真 security concern, 是 control 缺失 + 流程被跳过 + 个人 risk 担忧. 你的 job 不是 "证明 we're secure", 是让 IT 感受到他在控制 process + 给他 quantified checklist + 给他 veto 权.

🎯 5 个核心 framework

Framework 1: 6-Layer Real Concern (L1-L6) 识别

  • When: 收到 IT block 信号第一刻
  • Algorithm:
  • L1 Surface: data leaving network → checklist (SOC 2 / ISO / DPA)
  • L2 Control: oversight 缺失 → governance access + audit log
  • L3 NIH: internal alternative → make ally + joint platform
  • L4 Career: vendor failure = my fault → legal SLA + insurance
  • L5 Geopolitical: don't trust [country] → data residency
  • L6 Past trauma: previously burned → trust building over time
  • Trade-off: 误判 layer = 按错药, listen-only 50% before propose
  • Tools: 1:1 with IT lead (not group call), open-ended questions, sponsor align

Framework 2: Security Control Inventory (10-Doc Package)

  • When: 知道 layer 后 customize
  • Algorithm:
  1. 1-pager security overview
  2. SOC 2 Type II + ISO 27001 + relevant cert
  3. Architecture + threat model (STRIDE)
  4. Encryption + BYOK detail
  5. Access control model (Zero Trust)
  6. Audit log schema + SIEM integration
  7. Data handling + residency
  8. IR runbook + insurance
  9. Pen-test summary (NDA-gated)
  10. Contract templates (MSA / DPA / BAA)
  • Trade-off: 给所有 = 信息淹没, 给 0 = 不信任
  • Tools: per-role tailoring (CISO exec brief / architect threat model / compliance audit / analyst SIEM / IT director governance)

Framework 3: 3-Tier Phased Rollout

  • When: IT 不让全量上线
  • Algorithm:
  • T1 (2w): sandbox non-prod, FREE, full audit access, IT veto
  • T2 (4w): prod single team, BYOK, daily review, discounted
  • T3 (12w+): broader scope, IT signoff each expansion, standard pricing
  • 每 stage IT veto authority (single kill-switch feature flag, customer holds credential, 24h on-call, no questions asked)
  • Trade-off: 慢, 但 IT 感觉 in control
  • Tools: feature flag (LaunchDarkly), audit log streaming, customer-controlled credential

Framework 4: 3-Way Working Session (IT vs Business 平衡)

  • When: 内部冲突需要中立 facilitate
  • Algorithm:
  • Restate goals (Business + IT 都 legitimate)
  • Identify constraints (both 角度)
  • Propose phased approach
  • Define exit criteria
  • Agree on cadence (weekly / biweekly)
  • Action items
  • Trade-off: 站任何一边都错, 必须 facilitator
  • Tools: meeting facilitator hat, structured agenda, exit criteria writeup

Framework 5: When to Commit vs Refuse (Push Back)

  • When: 客户 ask 超出工程能力
  • Algorithm:
  • Don't lightly commit:
  • On-prem deployment (6-12 month custom)
  • Air-gapped (radically reduce function)
  • FedRAMP (1-2 year process, 可能拿不到)
  • Unlimited liability (never)
  • Continuous pen-test (annual is industry)
  • Sub-hour breach notification (impossible)
  • Can commit:
  • SOC 2 + ISO 27001 + DPA + BAA + custom amendment
  • BYOK + per-tenant DEK
  • Data residency per-region (US / EU / SEA)
  • Audit log streaming to SIEM
  • Customer-paid pen-test annual
  • 24h breach notification
  • Cyber insurance certificate
  • Trade-off: yes 失底线, no 失关系, 平衡 craft
  • Tools: 内部 CISO pre-align ceiling, contract template library, escalation hierarchy

🌳 关键决策树

IT block 来源?
├── CISO (顶层) → Executive briefing + risk + insurance
├── Security architect → Architecture + threat model + control mapping
├── Compliance officer → SOC 2 + ISO + recent audit
├── Security analyst (执行层) → Log streaming + monitoring integration
└── IT director (中层) → Governance + minimal team overhead

Hard-block vs Soft-block?
├── Hard (政策 e.g., FedRAMP required, 你没) → 接受 reality, deal 可能死
├── Soft (流程慢) → 3-tier phased + IT veto + compliance package
└── Mixed → 识别 hard 部分先 escalate to leadership, soft 部分走流程

客户 ask 评估?
├── On-prem 必要? → 内部 EM align engineering cost
├── BYOK 必要? → ✓ commit (standard offering)
├── In-country residency? → 看 region 能力
├── Air-gap 必要? → 慎重 commit (function 受限)
└── FedRAMP? → 接受可能 deal 死

IT vs Business 冲突?
├── 站任何一边都错
├── 3-way working session facilitator
├── Restate both as legitimate
└── Propose phased with IT veto

⚙️ Part 2 五个深度问题速查

Problem 1: 4-Layer Concern Model (识别真因)

  • 核心解法:
  Listen-only call 30-min:
    Open: "What's your normal process for vendor review — let's go through it"
    Open: "I want to understand directly, not filtered"
    No deck, listen 50% time
  
  Layer identification:
    L1 surface: 给 SOC 2 checklist
    L2 control: governance access + audit log
    L3 NIH: ally + joint platform language
    L4 career: legal SLA + insurance + named escalation
    L5 geopolitical (China/Russia 等): data residency in-country
    L6 past trauma: 时间 + 透明
  • Top 3 gotchas: 一上来 list mitigations (没识别 layer) / argue with IT in group / NIH 当 obstinacy 误判
  • Tools/tactics: open-ended questions, 1:1 not group, no deck listen-only first

Problem 2: Security Control Inventory (10-Doc + Per-Role)

  • 核心解法:
  Per-role 1-pager (不要 dump 50-page SOC 2):
    CISO: Executive briefing + risk + cyber insurance certificate
    Architect: Architecture diagram + STRIDE threat model + control mapping
    Compliance: SOC 2 Type II + ISO 27001 + recent audit summary
    Analyst: Audit log schema + SIEM integration (Splunk / Datadog / Sumo)
    IT director: Governance model + IT veto authority + minimal team overhead
  
  Standard checklist tick:
    ✓ AES-256 at rest, TLS 1.3 in transit
    ✓ Per-tenant DEK + customer KEK (BYOK)
    ✓ SOC 2 Type II + ISO 27001
    ✓ DPA + BAA + custom amendments
    ✓ Audit log streaming to customer SIEM
    ✓ Customer-paid pen-test annual
    ✓ Data residency per region
    ✓ Just-in-time engineer access
    ✓ 24/7 on-call + 24h breach notification
    ✓ Cyber insurance certificate
  • Top 3 gotchas: generic 50-page dump / 没 per-role tailor / 没 SIEM integration story
  • Tools/tactics: CAIQ / CCM pre-filled library, quarterly update, 24h SLA return

Problem 3: Compliance / Certifications Proof Package

  • 核心解法:
  Industry mapping:
    Healthcare: SOC 2 + HIPAA + BAA
    Financial: SOC 2 + PCI DSS + SOX
    EU enterprise: SOC 2 + ISO 27001 + GDPR DPA
    US federal: FedRAMP (1-2yr, accept reality if don't have)
    Indonesia BNPL: OJK 认证 + 本地 KYC compliance
  
  Audit-ready:
    Recent SOC 2 audit < 12 months old
    Customer audit access portal (Vanta / Drata)
    Quarterly attestation update
    Pen-test annual + remediation tracking
  
  Contract templates:
    MSA (Master Service Agreement)
    DPA (GDPR)
    BAA (HIPAA)
    Custom amendments per customer
  • Top 3 gotchas: SOC 2 outdated (> 12 月) / 没 industry-specific cert / 没 audit access portal
  • Tools/tactics: Vanta / Drata compliance automation, audit report library, contract template versioning

Problem 4: Pilot / Sandbox / POC (Build Trust Incrementally)

  • 核心解法:
  T1 Sandbox (2 weeks):
    Non-prod data, synthetic + masked
    FREE (no cost)
    Full audit access to customer IT
    IT has veto + kill switch single command
    Goal: prove integration works, build trust
  
  T2 Restricted Prod (4 weeks):
    Real prod data 1 team only
    BYOK customer-controlled encryption
    Daily review with customer IT
    Discounted pricing
    Goal: prove production-grade
  
  T3 Broader (12+ weeks):
    Expanded scope, more teams
    IT signoff at each expansion
    Standard pricing
    Goal: gradual scale
  
  IT-veto principle:
    Single kill-switch command (feature flag)
    Customer holds credential
    24h on-call escalation
    No question asked when invoked
  • Top 3 gotchas: 全量上线没 phasing / 没 customer-controlled kill switch / IT 不在 veto authority
  • Tools/tactics: LaunchDarkly feature flag, customer credential vault, 24h on-call rota

Problem 5: IT vs Business Conflict (3-Way Working Session)

  • 核心解法:
  Facilitator hat:
    Don't side with either
    Restate both as legitimate
    "Business needs X, IT needs Y, both legitimate"
  
  3-Way agenda:
    1. Restate goals (Business + IT)
    2. Identify constraints (both legitimate)
    3. Propose phased with IT veto
    4. Define exit criteria
    5. Cadence (weekly / biweekly)
    6. Action items
  
  Sales pressure to escalate over IT:
    Public: 不当面反驳
    Private: "Escalating burns IT permanently. Phased + IT veto faster long-term"
    AE 坚持: escalate manager. Don't put your name on bypass
  • Top 3 gotchas: 站 sales 边 (IT 永敌) / 站 IT 边 (business sponsor 失) / escalate over IT to CIO
  • Tools/tactics: facilitator hat, 3-way working session, 不 cut-throat sales escalation

🔥 Production gotchas (top 15)

  1. Escalate over IT to CIO → IT 永久敌对, 续约 block
  2. Skip IT review process → burning bridge
  3. Argue with IT in group call → 公开 loss, IT 面子受损
  4. Promise "我们 secure" without checklist → hand-wave dismiss
  5. Blame sales VP to IT → internal disloyalty
  6. NIH 当 obstinacy 误判 → 错失 ally 机会
  7. 没 phased option → all-or-nothing 死
  8. Over-promise on-prem / air-gap → 工程做不到, explode
  9. 没 read who blocked (CISO vs analyst) → 按错药
  10. 50-page SOC 2 generic dump → IT 看 5 分钟跳走
  11. 没 internal CISO align before commit → 后续否决
  12. 客户 sponsor 落单不联络 → 失内部 champion
  13. Skip 1:1 直接 group → 公开冲突
  14. 没 SIEM 集成 → analyst 信号缺失
  15. Audit log 不 streaming → 客户事后无法 review
