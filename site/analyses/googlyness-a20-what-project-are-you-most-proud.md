# 🟡 G20 · What project are you most proud of?

> **信号**: 价值观 · 你以什么为豪 · **hellointerview 报告数**: 2

## 🧠 这题在测什么

与 Q10 (most impactful) 区分: impact 给 voice agent, proud 给 platform — 以'让别人成功'为豪本身就是 Googlyness 信号.

## 📋 English Answer (背诵稿, ~60-90 秒)

Impact-wise my biggest project is the voice agent — but the one I'm proudest of is the Internal Agent Platform, because of *what kind* of work it was.
It started from a pattern, not an assignment: shipping the chatbot's second market, I noticed every team in Global Payment was about to re-solve the same five problems — workflow orchestration, tool integration, memory and state, observability, evaluation. So I co-designed a shared platform as algorithm POC: those five concerns as infrastructure, per-team configuration on top, deployment standards baked in.
The pride comes from three things. It was proactive — I recruited co-sponsor teams and proved demand before asking leadership for anything. It compounds — every team that builds on it ships faster than we did, which is the point [✏️ 接入团队数核实]. And it forced the deepest design thinking of my career: platform APIs are promises you can't easily take back, so every abstraction had to survive use cases I couldn't foresee.
The voice agent proved I can ship hard systems. The platform is the project where my work became other teams' velocity — and that's the kind of engineer I want to keep being.

## 🇨🇳 中文完整版 (口播稿, ~60-90 秒)

论 impact 最大是 voice agent, 但我最自豪的是内部 Agent Platform — 因为那是一种不同「类型」的工作.
它始于一个模式而非任务: 做 chatbot 第二个市场时, 我看到 Global Payment 每个团队都即将重复解同样五个问题 — workflow 编排、工具集成、记忆与状态、可观测、评估. 于是我以算法 POC 身份共同设计了共享平台: 五件事下沉为基础设施, 每团队在上面只做配置, 部署标准内建.
自豪来自三点. 它是主动的 — 我先找好 co-sponsor 团队、证明了需求, 才向 leadership 要资源. 它有复利 — 每个基于它构建的团队都比我们当初更快, 这正是意义所在 [✏️ 接入团队数核实]. 它逼出了我职业生涯最深的设计思考 — 平台 API 是收不回的承诺, 每个抽象都必须在我预见不到的用例下活下来.
voice agent 证明我能 ship 困难的系统; platform 是我的工作变成其他团队速度的项目 — 那是我想持续成为的工程师.

Invest in self-serve onboarding earlier — early adopters needed too much hand-holding from me, which capped adoption speed at my calendar.
